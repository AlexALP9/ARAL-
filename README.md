# ARAL — сайт из утверждённых HTML-черновиков

**Публичная версия:** https://alexalp9.github.io/ARAL-/

После корректировки интеграции сайт открывает исходную редакцию «Компания» из V8, а не старую заново нарисованную главную страницу. Все семь разделов соединены прямой навигацией, без iframe, дополнительной шапки, смены шрифтов или переписывания текстов.

## Семь утверждённых разделов

| Раздел | Источник | Публикуемый путь |
|---|---|---|
| Компания | V8 | `index.html#company` |
| Продукция | revision 15 | `pages/products-r15.html#/catalog` |
| Для водителей | редакция 08 | `pages/drivers-08.html` |
| Для партнёров | редакция 11 | `pages/partners-11.html` |
| Преимущества ARAL | редакция 04 | `pages/advantages-04.html` |
| Интересное | V8 | `index.html#interesting` |
| Контакты | редакция 03 | `pages/contacts-03.html` |

Код оригинальных черновиков хранится отдельно в `src/pages/`. Публичные HTML отличаются только исправлениями перекрёстных ссылок, путей к изображениям, возврата на главную по логотипу и блокировщика навигации, оставшегося от автономного каталога.

## Структура

- `index.html` — страница «Компания» и «Интересное» с оригинальным роутером V8.
- `pages/` — остальные пять HTML-страниц с их собственными стилями и скриптами.
- `src/pages/` — исходные черновики, без перезаписи.
- `media/editorial/` — 33 встроенных редакционных изображения, вынесенные в отдельные файлы, **с байт-в-байт сохранением оригиналов**; для V8 сохранены корректные расширения JPG/PNG/WebP.
- `media/production/` — 47 исходных изображений продуктовых SKU.
- `catalog.json` и `current/catalog/` — существующие JSON-данные продукции, сохранённые без изменений; HTML revision 15 поддерживает свой утверждённый набор данных/интерактивность. **Не следует путать это с серверной базой данных.**
- `current/master/` — утверждённый технический MASTER, не менять без отдельного согласования.
- `archive/` — исходная главная, старые версии и исторические материалы.
- `docs/` — документация и правила публикации.
- `.github/workflows/pages.yml` — сборка и размещение на GitHub Pages.

## Технический подход

Это **статический многостраничный сайт**, где роутинг V8 и каталога работает внутри соответствующих HTML. Такой вариант выбран для точного сохранения утверждённого вида страниц; это **не** новый React SPA и **не** iframe-оболочка. Дальнейшая миграция на компоненты возможна только при сохранении визуальной идентичности после тестирования.

## Проверка и публикация

Публикация происходит через GitHub Actions при изменениях в `main`. Workflow проверяет наличие 17 продуктов / 47 SKU в сохранённой JSON-базе, 33 редакционных файлов и всех заявленных ссылок на фото, наличие шести HTML-документов для семи разделов. Успешный workflow подтверждает публикацию файлов, **но не заменяет полноценную визуальную проверку всех интерактивных сценариев на нескольких экранах**.

Документация: [архитектура](docs/FINAL_ARCHITECTURE.md), [правила PDS/SDS](docs/README.md), [сведения об источниках PDS/SDS](docs/sources.json). Не публиковать заблокированные PDS/SDS. Цены, контакты и технические допуски не дописывать по догадке.

## Быстрый локальный просмотр

Файлы `index.html` и `pages/*.html` используют относительные пути. Для корректной загрузки локальных ресурсов запускайте статический HTTP-сервер из корня репозитория (например `python3 -m http.server 8000`), после чего откройте http://localhost:8000/. GitHub Pages собирается из разрешённого публичного подмножества репозитория.
