# ARAL

Рабочий репозиторий проекта монобрендового сайта ARAL.

## Статус переноса
- Найдено в ChatGPT Project: **118** файлов/артефактов.
- Текстовые слои, отчёты, ТЗ, промты и архивные версии перенесены и структурированы.
- В репозитории сейчас **55 файлов**.
- Бинарные исходники (XLSX/PDF/DOCX/ZIP/изображения) перечислены в `PROJECT_FILE_INVENTORY.md`; часть из них требует ручной загрузки из-за ограничения текущего GitHub-коннектора на прямой raw-byte перенос из Project Files.
- Текущий production/public слой, созданный локально в Codex/Work, отсутствует в Project Files и перечислен в `MISSING_FILES.md`.

## Текущий проект
- 17 продуктов
- 47 SKU / вариантов фасовки
- `current/master/` — frozen technical source of truth
- `current/content/` — актуальный content layer
- `current/media/` — текущие доступные media manifests/maps/reports
- `current/catalog/` — место для production/public catalog после загрузки недостающих файлов
- `archive/` — старые версии
- `research/` — исследования и PDS-материалы
- `design/` — ТЗ, ветки, Figma briefs, workflow/prompts

## Ключевые правила
- `ARAL_PRODUCT_MASTER_v1.2` — **FROZEN / READ ONLY**.
- Не подменять отсутствующие актуальные production/public файлы старыми версиями.
- Для Figma/frontend использовать `ARAL_PUBLIC_CATALOG_v1` + `ARAL_PRODUCTION_MEDIA_MAP_v1` + `media/production/`, когда они будут добавлены.
- Медиа-одобрение не меняет технический статус продукта.

## Навигация
- `PROJECT_FILE_INVENTORY.md` — полный список Project Files и статус переноса.
- `MISSING_FILES.md` — чего не хватает для полного handoff в Figma/frontend.
- `SECURITY_NOTES.md` — заметки по публичному репозиторию.

## Скачать PDS и SDS из карточек товаров

В разделе «Документация» на карточке продукта появились отдельные кнопки **«Скачать паспорт продукта (PDS)»** и **«Скачать паспорт безопасности (SDS)»**. Они показываются только при наличии PDF в опубликованной сборке; для самостоятельного поиска всегда доступна официальная страница ARAL.

- [Подробная инструкция по загрузке и публикации PDF](docs/README.md)
- [Источники документов и права публикации](docs/sources.json)
- [Скрипт проверки и подготовки PDF](scripts/build_docs.py)
- [GitHub Pages workflow](.github/workflows/pages.yml)

**Внимание:** загруженные в чат PDF не обязательно уже существуют в GitHub. Их исходные бинарные файлы нужно разместить в `docs/pds/` и `docs/sds/` либо дать проверяемые прямые URL производителя. Frozen MASTER не изменяется, заблокированные PDS не публикуются автоматически.


## Актуальное состояние — 27 октября 2026

Текущий публичный интерфейс работает на статическом JavaScript SPA и читает `catalog.json`. Каталог содержит **17 продуктов / 47 SKU**. Рабочие изображения: `media/production/` (47 файлов), исторические копии исходников: `archive/original-root-images/` (47 файлов). Старый frontend сохранён в `archive/site-before-integration/`.

Систематизация и индекс материалов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [archive/README.md](archive/README.md). Проверка ссылок на товарные фото: `python3 scripts/validate_catalog.py`.

**Семь утверждённых HTML-страниц пока не интегрированы в опубликованный SPA.** Самостоятельный локальный preview из этих исходников создавался отдельно и должен пройти полноценную интеграцию, тесты и публикацию. Прежние разделы README ниже являются историческим описанием переноса и могут отражать состояние до добавления каталога.
