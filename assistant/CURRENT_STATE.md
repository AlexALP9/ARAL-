# ARAL — текущее состояние

**Актуализация:** 2026-10-24. **Назначение:** компактный рабочий срез, не новый аудит. **База для будущего PR:** `https://github.com/AlexALP9/ARAL-` → `main` (публичный; проверено через GitHub-коннектор 2026-10-24). **В GitHub сейчас ничего не записано.**

## Проект

Монобрендовый сайт масел ARAL; аудитория ориентировочно **70% B2B / 30% B2C**. Задача — представить бренд и товары, приводить к покупке/связи через «Склад СПК», собственные магазины и партнёров. Не выдавать СПК за производителя ARAL. Архитектура рассчитана на каталог свыше 50 товаров в перспективе и на 100+ SKU; фактический текущий технический набор ранее описывался как **17 продуктов / 47 SKU** — это разные уровни счёта, не тождественные показатели.

## Установленные рабочие ориентиры

- Страницы из обсуждения: **«Компания», «Продукция», «Для водителей», «Для партнёров», «Контакты»**. Их окончательный порядок блоков не перепроверен по отсутствующим `SRC-02/03`: см. `D-STR-01`.
- Для страницы «Компания» есть два текстовых материала о производственной истории и специалистах; дословные редакции сохранены в [APPROVED_TEXTS.md](APPROVED_TEXTS.md). Различать **специалистов по созданию масел ARAL** и **менеджеров-консультантов СПК**: последние предназначались «Для водителей» и «Для партнёров», не «Компания».
- Пользователь указал, что HERO утверждён, и не просил пересогласования. Публикация/соответствие `main` этому утверждению не проверялись.
- Для кнопки «Купить» пользователь указал **конкретную карточку товара СПК по ранее подготовленной таблице**. Применимость такого пути к розничному покупателю — открытый вопрос, не повод менять направление самому.
- У карты принято имя «Наши партнёры», вкладки «Москва/область» и «Россия», схема «Где купить» — покупатели и оптовики/партнёры как две части.

Полный набор решений со статусами: [DECISIONS.md](DECISIONS.md).

## Где остановились

Предыдущая работа: разбор исторического архива и определение статусов. Текущая задача этого этапа — **подготовить публично безопасный переносимый контекст помощника для отдельного PR**. Сформирован локальный пакет пяти `.md`, но в GitHub он **не записан**. Разработка сайта, технический аудит и перенос архивов сейчас **не выполняются**.

**Следующее обоснованное действие:** пользователь просматривает пять Markdown-файлов, уточняет спорные записи при необходимости и **отдельно подтверждает** создание ветки и PR. До этого — read-only.

## Существенные открытые вопросы и пределы

1. **Доступ к `SRC-02` и `SRC-03` отсутствовал**, поэтому сверка частей А/Б и полной дельты невозможна; это не блокирует создание пяти консервативных файлов, но мешает назвать синхронизацию полной.
2. Полный исходный архив содержит внутреннюю переписку и не предлагается к публикации в **публичном** репозитории.
3. Результаты «HTML-черновик Компания», «timeline v4», исходные изображения утверждённых макетов, данные торговых точек и файлы фотографий обсуждались/сообщались в чатах, но их текущая доступность и внедрение здесь не перепроверялись. Не пересоздавать без запроса.
4. Дословная редакция истории производства есть в `SRC-01`; её принятие к использованию описано **во вторичном сообщении**. Первичное подтверждение всего текста в доступном комплекте не проверено. Ни это сообщение, ни выбор редакции не являются проверкой фактов о производстве перед публикацией.
5. В старой переписке был конкретный срок; он сохранён в приватном `SRC-01`, не публикуется в этом публичном контексте. При возобновлении уточняй его актуальность; срок не даёт разрешение на изменения.

Проверка `GH-MAIN` была **минимальной**: видимость, основная ветка, список корня, инструкции `README.md` / `SECURITY_NOTES.md`, наличие каталогов. Ни работоспособность сайта, ни все PR, ни фактические SKU/PDF сейчас не проверены.
