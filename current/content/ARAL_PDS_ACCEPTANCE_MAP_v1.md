## Пояснения

- Принято 18 уникальных PDS для 16 масел. HighTronic 5W-40 сохранён в двух EN-редакциях: 2022-03-21 и 2024-11-07.
- wepp-d85j7j.pdf: rejected_identity_mismatch; общее SuperTronic 0W-20 не приравнено к Longlife IV FE.
- wepp-dbd8r2.pdf: точный Longlife III, 2024-11-25; Advantages отсутствует как самостоятельный раздел.
- wepp-d8te3h.pdf: точный LL IV FE, 2024-09-04; SP/GF-6 сохранены только в этой редакции.
- Extra/Plus: user_confirmed по прямому указанию пользователя; никаких дополнительных доказательств производителя о SKU не заявлено. Названия источников хранятся в provenance.
- Silikatfrei: только user_provided_manual_reference, не принятый официальный PDS.
- Неизвестные URL/рынок/серверный ключ не восстановлены по догадке. Local filename не равен автоматически серверному document key.
- Revision relation сравнивает даты принятых файлов с Main PDS в MASTER; null для Extra/Plus означает отсутствие назначенной базы сравнения.
- Исходный batch_2_check оставлен без изменений как история проверки; его отказы только по языку/дате отменены этой картой.
