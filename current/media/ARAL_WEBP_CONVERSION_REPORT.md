# ARAL — lossless WebP conversion report

47 принятых пользователем изображений сохранены в media/originals без изменений. Отдельные WebP-копии находятся в media/web. Фоны, этикетки, кадрирование, цвета и размеры не изменялись.

## Источник

Использованы 47 уже существующих отдельных файлов ARAL_MEDIA_ORIGINALS_RAW. Для каждого подтверждено побайтовое совпадение с соответствующим xl/media-объектом ARAL_catalog_final.xlsx и точная привязка к SKU. Это оригиналы встроенных принятых изображений, а не заявление о наличии более ранних файлов камеры/дизайнера.

В ранее указанной папке «ФОТО ARAL» есть другие изображения, но их bytes не совпадают с принятыми изображениями. Они не подставлены по сходному имени вместо текущего утверждённого фото. Внешние исходные пути остаются неизвестными.

## Проверка качества

Для каждого файла проверены существование, открытие WebP, ненулевые размеры, отсутствие пустого одноцветного изображения, совпадение ширины/высоты, принадлежность SKU manifest и public map. Дополнительно проверены lossless-блок VP8L и точное равенство декодированных RGBA-пикселей исходника и WebP. Все 47 проверок пройдены. Это подтверждает отсутствие добавленного визуального ухудшения, включая фон и мелкие надписи; исходные JPEG-артефакты не устранялись.

Служебные JFIF-поля/комментарии JPEG не являются пикселями; исходный JPEG сохранён целиком. ICC/EXIF/XMP передаются при наличии; в текущих исходниках таких профилей/данных нет.

## Данные для сайта

Разместить содержимое media/ в корне статических ресурсов сайта, чтобы пути /media/web/... были доступны. ARAL_PUBLIC_MEDIA_MAP.json содержит только 17 product IDs и 47 variants с volume/image. Ключ выбора: internal_id + SKU. Пример привязки HTML select к img — ARAL_MEDIA_VOLUME_SELECT.ts. Изменение selectedSku вызывает повторный выбор точного variant и обновляет img.src. При неизвестном SKU изображение другого варианта не подставляется. Сам сайт этой задачей не создан.

Для общих бочек image_role=generic_package_representation; уникальная этикетка конкретного масла не заявляется. Extra 20 L / 22003: media_status=approved_by_user. Медиаодобрение не меняет технические разрешения MASTER.
