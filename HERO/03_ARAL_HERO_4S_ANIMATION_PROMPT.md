# ARAL HERO — 4-секундная анимация продукта

## Статус
Утверждённое направление для Hero. Этот файл фиксирует механику анимации, композицию и ограничения. Не заменяет текущий production Hero без отдельного подтверждения.

## Источники и приоритет
1. **Видео LIQUI MOLY, приложенное пользователем в Work-чате** — анализировать начиная примерно с 4-й секунды. Использовать только механику камеры, ритм и принцип раскрытия продукта; не копировать фирменную графику, тексты и бренд.
2. **Референсный кадр ARAL, приложенный пользователем** — использовать только ракурс крупного плана и характер светлого холодного фона.
3. `HERO/ARAL_HERO_4S_STORYBOARD.jpg` — референс тайминга и общей композиции. Если на сториборде есть неточная этикетка или название, **игнорировать это**.
4. **Точные фотографии товаров пользователя / `media/production/`** — единственный источник внешнего вида канистр, этикеток, логотипов и пропорций.

## Жёсткая блокировка товаров
В кадре с литровыми продуктами должно быть **ровно 3 канистры 1 L**. Никогда не создавать четвёртую.

В Work-чате сопоставить:
- `MAIN_1L` = первая / главная из трёх утверждённых пользователем фотографий;
- `SIDE_1L_A` = вторая фотография;
- `SIDE_1L_B` = третья фотография.

Если используется исходная тройка из репозитория:
- `media/production/ARAL-010_15DBCC_1L.jpg` — Aral Super Tronic K 5W-30;
- `media/production/ARAL-012_15F45F_1L.png` — Aral Super Tronic Longlife IV FE 0W-20;
- `media/production/ARAL-006_21407_1L.jpg` — Aral High Tronic M 5W-40.

Если в Work-чате пользователь приложил более новый утверждённый главный 1L packshot, он заменяет только `MAIN_1L`; общее количество всё равно остаётся **3 × 1 L**.

Дополнительные продукты появляются **только в финале**:
- слева: `media/production/ARAL-015_22003_20L.png` — 20 L;
- справа: `media/production/ARAL-011_160EC7_5L.jpg` — 5 L;
- по центру сзади всех: `media/production/ARAL-016_22119_208L.jpg` — бочка ARAL.

Не перерисовывать и не генерировать упаковку. Не менять форму, цвет пластика, логотип, текст этикетки, крышку и пропорции.

## Таймлайн 4.0 сек

### 0.0–0.7 сек — экстремальный крупный план
- Hero уже имеет светлый холодный premium-фон.
- Камера визуально находится очень близко к `MAIN_1L`.
- В кадре крупно видна фактура синего пластика и часть этикетки/логотипа.
- Ракурс — как у утверждённого ARAL-кадра пользователя: продукт занимает правую половину/правую зону, слева остаётся воздух под текст Hero.
- Никаких дополнительных канистр пока нет.

### 0.7–1.4 сек — камера отъезжает и поднимается
- Создать ощущение, что камера плавно отъезжает назад и одновременно идёт вверх.
- На короткий момент акцент переходит на верх канистры и крышку.
- Движение должно ощущаться как реальный camera move, но может быть реализовано 2D/2.5D через scale + translate + transform-origin + mask.
- Без резких zoom-out и без вращения самой упаковки.

### 1.4–2.0 сек — переход к этикетке и полной канистре
- Камера продолжает отъезд.
- Движение мягко опускает взгляд по фронтальной части продукта к этикетке.
- К ~2.0 сек главная литровая канистра читается почти целиком.
- Она остаётся главным и самым крупным объектом.

### 2.0–2.7 сек — раскрытие трёх 1 L
- Из-за главной канистры в разные стороны раскрываются `SIDE_1L_A` и `SIDE_1L_B`.
- Механика: небольшое смещение из-за центрального объекта + opacity 0→1 + scale примерно 0.94→1.
- Получается веер, близкий по принципу к LIQUI MOLY.
- В кадре **ровно три** литровых продукта: главная + две боковые.
- Боковые не должны конкурировать с центральной по масштабу.

### 2.7–3.2 сек — фиксация основной тройки
- Три 1 L продукта плавно занимают финальные позиции.
- Допустим едва заметный parallax/depth.
- Никаких 5 L, 20 L и бочки до этого момента.

### 3.2–4.0 сек — финальное расширение линейки
Только после завершения основной анимации появляются крупные форматы:
- 20 L — сзади/слева основной тройки;
- 5 L — сзади/справа, симметрично по смыслу 20 L;
- 208 L бочка — поднимается/проявляется **по центру за всеми остальными** и является самым дальним слоем.

Их появление должно быть коротким и аккуратным:
- translate 20–50 px;
- opacity 0→1;
- scale 0.96→1;
- лёгкий stagger.

К 4.0 сек получаем законченную композицию:
**20 L слева → 3 × 1 L спереди → 5 L справа → бочка ARAL по центру сзади.**

## После 4.0 сек
- Не перезапускать intro сразу по кругу.
- Оставить статичный финальный кадр с очень слабым живым parallax.
- При следующем смысловом scroll можно начать переход к следующему блоку.

## Визуальный язык
- light premium;
- холодный бело-серо-голубой фон;
- мягкая тень под продуктами;
- без тяжёлого automotive-фона;
- без neon / glassmorphism / AI-look;
- продукт должен выглядеть как реальная предметная съёмка;
- слева сохраняется пространство для Hero copy и CTA.

## Техническая реализация
Предпочтительно:
- CSS transforms + opacity + masks;
- GSAP timeline / ScrollTrigger либо Motion — только если реально нужен контроль таймлайна;
- 2D/2.5D, без тяжёлого WebGL.

Анимация не должна менять данные каталога и не должна требовать генерации новых packshot.

## Accessibility
Для `prefers-reduced-motion`:
- пропустить camera move;
- показать финальную композицию почти сразу;
- использовать короткий fade 150–250 ms.

## Критерий приёмки
Результат должен восприниматься как короткая премиальная продуктовая съёмка ARAL:
**макро → крышка → этикетка/полный продукт → веер из 3 × 1 L → только в самом конце 20 L + 5 L + центральная бочка.**
