# HERO

Папка с промтами для разработки первого экрана сайта ARAL.

## 01_HERO_LIQUI_MOLY_STYLE_PROMPT.md
Промт для создания/прототипирования Hero:
- светлый premium;
- крупный product focus;
- реальные канистры ARAL;
- desktop/mobile;
- лёгкий motion;
- без копирования чужого дизайна 1:1.

Использовать сначала для Figma / дизайн-прототипа.

## 02_INTEGRATE_HERO_INTO_EXISTING_SITE_PROMPT.md
Промт для внедрения утверждённого Hero в текущий production-сайт AlexALP9/ARAL-.

Он требует:
- не ломать каталог;
- не менять MASTER/CONTENT/PUBLIC CATALOG;
- сохранить B2B/B2C;
- сохранить GitHub Pages;
- использовать реальные изображения из media/production/.

## Рекомендуемый порядок
1. Сначала использовать промт №1 и утвердить визуал.
2. После утверждения использовать промт №2 для интеграции в текущий сайт.
3. После внедрения проверить desktop/mobile и GitHub Pages build.
