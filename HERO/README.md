# HERO

Папка с актуальными промтами и спецификациями первого экрана сайта ARAL.

## Статусы

### 01_HERO_LIQUI_MOLY_STYLE_PROMPT.md
**Статус: SUPERSEDED AS PRIMARY / вспомогательный визуальный референс.**

Содержит раннюю формулу светлого premium Hero:
- крупный product focus;
- много воздуха;
- реальные канистры ARAL;
- desktop/mobile;
- лёгкий motion;
- без копирования чужого дизайна 1:1.

Использовать только как общий визуальный ориентир. Для актуального motion-сценария приоритет ниже, чем у файла `03_ARAL_HERO_4S_ANIMATION_PROMPT.md`.

### 02_INTEGRATE_HERO_INTO_EXISTING_SITE_PROMPT.md
**Статус: DRAFT / integration prompt.**

Промт для последующего внедрения утверждённого Hero в production-сайт.
Не использовать до отдельного подтверждения интеграции.

### 03_ARAL_HERO_4S_ANIMATION_PROMPT.md
**Статус: APPROVED — актуальная motion-спецификация Hero.**

Зафиксирован последний утверждённый сценарий:
1. около 4 секунд;
2. экстремальный крупный план главной 1L канистры;
3. плавный отъезд и подъём камеры;
4. акцент на крышке;
5. переход к этикетке / полному продукту;
6. появление ещё двух 1L канистр веером;
7. ровно три 1L в основной композиции;
8. только в финале появляются 20L, 5L и центральная бочка ARAL;
9. светлый студийный premium-фон;
10. внешний вид упаковок — только по реальным изображениям продуктов, без изменения этикеток.

### 04_WORK_PROMPT_ARAL_HERO_4S.md
**Статус: APPROVED WORKING PROMPT.**

Рабочий prompt для создания изолированного прототипа на основе спецификации №03.
Не даёт разрешения менять production Hero или код сайта без отдельного подтверждения.

## Product identity lock
Приоритет источников внешнего вида:
1. новые явно утверждённые пользователем реальные product photos;
2. `media/production/`;
3. storyboard/reference — только для композиции и тайминга.

Нельзя:
- перерисовывать этикетки;
- менять логотип;
- менять форму и цвет упаковки;
- использовать AI-сгенерированную упаковку как источник истины.

1. Использовать `03_ARAL_HERO_4S_ANIMATION_PROMPT.md` как source of truth по motion.
2. Использовать `04_WORK_PROMPT_ARAL_HERO_4S.md` для изолированного prototype/preview.
3. Проверить desktop / tablet / mobile / prefers-reduced-motion.
4. После пользовательского подтверждения отдельно решать вопрос production-интеграции.
