# ARAL — структура сайта: B2B / B2C

## Главная идея
Использовать логику Kärcher и разделить сайт на два понятных верхнеуровневых направления:

- **Для бизнеса**
- **Для автомобиля**

Не использовать как основные названия «Коммерческое / Личное авто»: слово «коммерческое» может восприниматься как коммерческий транспорт.

## Для бизнеса
- магазины и сети автозапчастей;
- автосервисы и СТО;
- оптовые компании;
- автопарки;
- коммерческий транспорт;
- условия сотрудничества;
- ассортимент и фасовки;
- документация;
- менеджер;
- обучение и помощь партнёрам.

## Для автомобиля
- подбор масла;
- каталог;
- выбор по вязкости;
- выбор по допускам;
- линейки ARAL;
- где купить;
- полезные материалы.

## UX
После выбора направления можно приоритизировать соответствующий контент:
- B2B — ассортимент, фасовки, опт, документация, менеджер;
- B2C — подбор, применение, допуски, товары, точки продаж.

## Открытые вопросы
- Поместить выбор двух направлений прямо в hero или сразу под ним.
- Запоминать ли выбранный сценарий в рамках сессии.
