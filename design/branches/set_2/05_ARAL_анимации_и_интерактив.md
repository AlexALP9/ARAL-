# ARAL — анимации и интерактив

## Scroll storytelling
Понравилось ощущение отдельных «страниц» при скролле.

Использовать в 1–2 сильных секциях:
- технологии;
- преимущества;
- подбор;
- B2B-сценарии;
- путь к покупке.

## Кастомный курсор
На desktop:
- Открыть
- Подробнее
- Листать
- Смотреть

Минималистичный, в цветах ARAL, без помех работе; на mobile отключить.

## Блок брендов / партнёров
Понравилось:
- бесконечная горизонтальная прокрутка;
- все логотипы в одном цвете;
- премиальный единый вид.

Для ARAL использовать только реальные подтверждённые бренды/партнёров.

## Отзывы
- крупные карточки;
- B2B и B2C можно разделить;
- короткая сильная цитата;
- имя / компания / роль;
- при наличии — логотип.

## Принцип motion
Анимация должна объяснять, направлять и усиливать бренд, а не превращать сайт в демонстрацию эффектов.
