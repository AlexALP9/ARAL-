# ARAL — карта веток диалога

Дата фиксации: 07.10.2026

Этот файл разделяет текущий диалог по сайту ARAL на независимые рабочие темы, чтобы дальше каждую можно было развивать отдельно.

## Ветки
1. 01_ARAL_структура_B2B_B2C.md — разделение «Для бизнеса» / «Для автомобиля».
2. 02_ARAL_визуальный_язык_и_референсы.md — Kärcher, LIQUI MOLY, STIHL, тёмные automotive-референсы.
3. 03_ARAL_меню_и_навигация.md — mega-menu и верхняя навигация.
4. 04_ARAL_каталог_карточки_акции.md — каталог, фильтры, промо-метки, teaser-карусель.
5. 05_ARAL_анимации_и_интерактив.md — scroll storytelling, курсор, логотипы, отзывы.
6. 06_ARAL_терминология_и_контент.md — терминология ARAL Lubricants Germany.
7. 07_ARAL_B2B_контент_для_партнеров.md — экспертный B2B-раздел.

## Общие решения
- Сайт монобрендовый ARAL.
- Аудитория ориентировочно 70% B2B / 30% B2C.
- Каталог должен масштабироваться до 100+ товаров.
- Основа визуала: чистый корпоративный стиль, много воздуха, качественные фото, сильная типографика, умеренные анимации.
- EON EV исключён полностью.
- Официальный ARAL — источник терминологии и продуктовой логики; внешние сайты — UX и визуальные механики.
