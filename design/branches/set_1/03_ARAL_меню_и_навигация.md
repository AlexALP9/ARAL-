## Анимация

- hover/click раскрывает mega-menu;
- знак `+` превращается в `×`;
- активный пункт слегка меняет фон/состояние;
- панель раскрывается сверху вниз;
- ориентир по длительности: 250–350 мс;
- при переключении разделов mega-menu желательно не закрывать целиком — менять только содержимое;
- колонки могут появляться с небольшим мягким сдвигом.

## Мобильная версия

Не повторять desktop mega-menu.
Использовать полноэкранное меню + аккордеоны.

## Требование к масштабированию

Навигация должна выдерживать 100+ товаров без превращения в длинный плоский список. Пользователь сначала выбирает группу/применение, затем переходит в каталог и фильтры.
