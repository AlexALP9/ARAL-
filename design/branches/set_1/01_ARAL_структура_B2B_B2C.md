# ARAL — структура сайта: B2B / B2C

## Главная идея

Использовать принцип Kärcher: на верхнем уровне не перегружать человека десятком сценариев, а сразу дать два понятных направления.

### Рекомендуемые названия

- **Для бизнеса**
- **Для автомобиля**

Формулировку «Коммерческое / Личное авто» не использовать как основную: «коммерческое» в автомобильной тематике может восприниматься как коммерческий транспорт, а не B2B.

## Ветка «Для бизнеса»

Внутри:
- магазины и сети автозапчастей;
- автосервисы;
- оптовые компании;
- автопарки;
- коммерческий транспорт;
- условия сотрудничества;
- ассортимент и фасовки;
- техническая документация;
- связь с менеджером;
- обучение и помощь партнёрам.

## Ветка «Для автомобиля»

Внутри:
- подбор масла;
- каталог;
- выбор по вязкости;
- выбор по допускам;
- линейки ARAL;
- где купить;
- полезные материалы по выбору и применению.

## UX-принцип

После выбора направления сайт может приоритизировать соответствующий контент:
- B2B — ассортимент, фасовки, оптовые сценарии, менеджер, документация;
- B2C — подбор, применение, допуски, товары, точки продаж.

## Почему это подходит ARAL

- не смешивает аргументы для двух разных аудиторий;
- позволяет сохранить единый бренд;
- упрощает первый экран и навигацию;
- соответствует приоритету B2B без ущерба для частного автомобилиста.

## Открытые вопросы

- Делать ли выбор «Для бизнеса / Для автомобиля» частью первого экрана или отдельным крупным блоком сразу под hero.
- Нужно ли запоминать выбранный сценарий в рамках сессии и слегка перестраивать следующие блоки.
