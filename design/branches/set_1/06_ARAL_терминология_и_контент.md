# ARAL — терминология и контент

## Главный источник

ARAL Lubricants Germany использовать как базовый источник:
- продуктовой терминологии;
- логики ассортимента;
- допусков и спецификаций;
- описания применений;
- фасовок;
- названий серий;
- технических документов.

При этом тексты для российского сайта должны быть проще и привлекательнее для клиента, но не придумывать свойства, которых нет в официальных материалах.

## Три уровня языка

### 1. Клиентский

Пример:
**Подберите масло ARAL для вашего автомобиля**

Подзаголовок:
Найдите подходящий продукт по автомобилю, вязкости и требованиям производителя.

### 2. Преимущество продукта

Не писать только сухие спецификации.
Сначала объяснять выгоду/назначение человеческим языком, затем подтверждать техническими данными.

Пример:
**Современное моторное масло для бензиновых, дизельных и гибридных автомобилей**

Далее — защита двигателя, сервисные интервалы, экономия топлива и т. п. только если это подтверждено официальными материалами конкретного продукта.

### 3. Профессиональный уровень

Показывать:
- SAE;
- ACEA;
- API;
- OEM approvals;
- техническое описание;
- паспорт безопасности;
- фасовки;
- область применения.

## Предпочтительный тон

Точные формулировки лучше общих рекламных клише.

Избегать без доказательств:
- «непревзойдённая защита»;
- «революционная технология»;
- «максимальная производительность»;
- «лучшее немецкое качество».

Предпочитать:
- соответствует конкретным требованиям;
- подходит для конкретных типов двигателей;
- рассчитано на определённые допуски;
- Low SAPS, LongLife и другие технические понятия — с коротким понятным объяснением.

## Рабочая формулировка позиционирования

Возможный вектор:
**Точно подобрано под требования вашего двигателя**

Нужна дальнейшая проверка на соответствие общей коммуникационной платформе ARAL.
