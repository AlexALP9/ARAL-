# ARAL — анимации и интерактив

## 1. Scroll storytelling

Понравился эффект, когда при обычном скролле пользователь как будто останавливается на отдельных смысловых «страницах».

Подходы:
- sticky storytelling;
- snap-like transitions;
- фиксированный визуал + меняющийся текст;
- последовательные экраны 01 / 02 / 03 / 04.

Для ARAL можно использовать в блоках:
- технологии;
- преимущества продукта;
- подбор масла;
- B2B-сценарии;
- путь от выбора к покупке.

Не применять на всём сайте. Лучше 1–2 сильных секции.

## 2. Кастомный курсор

На desktop курсор может менять состояние на интерактивных зонах:
- Открыть
- Подробнее
- Листать
- Смотреть

Требования:
- минималистичный;
- не мешает обычному использованию;
- фирменные цвета ARAL;
- отключается на mobile/touch.

## 3. Блок брендов / партнёров

Что понравилось:
- бесконечная плавная горизонтальная прокрутка;
- логотипы приведены к одному цвету;
- за счёт этого блок выглядит цельно и премиально.

Для ARAL:
- использовать только реальные подтверждённые бренды/партнёров/клиентов;
- монохром: графит, светло-серый или белый на тёмном фоне;
- hover может возвращать оригинальный цвет или усиливать контраст.

## 4. Отзывы

Понравилась подача крупными самостоятельными карточками.

Для ARAL:
- разделить B2B и B2C отзывы;
- короткая сильная цитата;
- имя / компания / роль;
- при наличии — логотип компании;
- не делать отзывы мелким текстом в стандартном слайдере.

## 5. Общий принцип motion-дизайна

Анимация должна:
- объяснять;
- направлять;
- создавать глубину;
- усиливать ощущение качества бренда.

Она не должна:
- тормозить путь к товару;
- скрывать важные элементы;
- делать сайт похожим на демонстрацию эффектов.
