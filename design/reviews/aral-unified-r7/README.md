Основа — R6, коммит `cc5febb9fbff52a4bed9b4e073862d139f41a64f`. Ветка ревью PR № 9. Восемь разделов используют семь HTML-файлов, компания и редакционные материалы имеют отдельные маршруты в одном файле.

## Разрешение на публикацию PDS

Владелец разрешил посетителям черновика открывать две редакции. Имена продуктов, даты и языки проверены по тексту PDF, выбор файлов — по `current/content/ARAL_PDS_ACCEPTANCE_MAP_v1.md`, контрольные суммы — по `current/content/ARAL_CONTENT_LAYER_v1.2.md`. R7 применяет версионное дополнение к замороженному `docs/sources.json` через [правила публикации R7](../../../assets/aral-pds-publication-r7.js). Эти правила содержат URL производителя и SHA-256 для каждой копии и используются самими карточками.

| Карточка | Заголовок производителя | Редакция | Страницы | Байт |
|---|---|---|---:|---:|
| ARAL-008 | Aral SuperTronic E 0W-30 | 02.06.2025, EN | 1 | 27 794 |
| ARAL-016 | Aral Turboral 15W-40 | 31.03.2025, DE | 2 | 37 335 |

Для ARAL-008 совпал также SHA-256 из `docs/sources.json`. Для ARAL-016 в старом реестре есть дата немецкого паспорта, пустой URL и хеш другого файла. Приёмка подтверждает привязку названия «Turboral (Plus)» к напечатанному «Aral Turboral 15W-40». Для R7 выбран немецкий оригинал с контрольной суммой `c3acf7c3ff785cba20f23f4289d81b0ff8163dc18e1febcaf54e7c6827141db3`. Разрешение касается конкретных файлов PDS. Прежние правила применяются к остальным редакциям, SDS и техническим характеристикам.

## Воспроизводимая проверка

Из корня репозитория запустите статический сервер на `127.0.0.1:8123`. При установленном Playwright и Chromium выполните следующие команды. Для системного Chromium можно передать путь через `CHROME_PATH`.

```sh
node design/reviews/aral-unified-r7/check-site.mjs
node design/reviews/aral-unified-r7/check-routes.cjs
```

Первый сценарий проверяет восемь разделов и оформление на 1440, 1024, 768 и 390 px, движение и возврат магнитных кнопок при наведении. Второй проверяет также каталог, сравнение, 16 карточек, фасовки, изображения, видимые ссылки и открытие двух PDS в отдельных вкладках с проверкой HTTP, типа и SHA-256. Результаты записываются в `review-output/aral-r7/`.
