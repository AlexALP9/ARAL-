# Карта дизайнерских решений — ARAL_HERO_MOTION_01A1556A

Дата проверки: 22.10.2026. Область: DESIGN / FIGMA / HERO / MOTION. Это индекс источников и статусов, а не новый общий дизайн-бриф.

Приоритет: последнее тематическое дополнение пользователя → совместимые явные решения этого чата → уже зафиксированные общие решения репозитория. Название папки `approved` и факт существования макета не являются подтверждением его утверждения.

## 1. Статусы

| Статус | Что означает здесь |
|---|---|
| APPROVED | Явно принятое требование или роль исходного материала; предел утверждения указан отдельно |
| DRAFT | Существующий, но не принятый макет/концепт; не готовый production-дизайн |
| REJECTED | Явно исключённый подход; не синоним отсутствия утверждения |
| SUPERSEDED | Предыдущая редакция, заменённая более поздним решением |

## 2. HERO: утверждено и не завершено

**APPROVED:** около 4 секунд, настоящие неизменённые изображения, светлая студия, макро → плавный отъезд и подъём → крышка → этикетка → веер из трёх 1L → только в конце 20L, 5L и центральная бочка. Главный Super Tronic K по центру впереди. Отдельная продуктовая сцена без copy/CTA; сайт не изменяется.

Точный приоритет и ссылки на существующие промпты: [сверка HERO](../../../HERO/ARAL_HERO_MOTION_01A1556A_RECONCILIATION.md).

**DRAFT:** существующие Figma-сцены; финальное соответствие новому заданию не принято. Полного утверждённого финального макета/видео этого чата не найдено.

**SUPERSEDED:** прежняя 6-секундная раскадровка v2. [Восемь исходных JPG](superseded/storyboard-v2/README.md) сохранены только как история варианта, который пользователь попросил улучшить. HTML/JS, SVG с повторно встроенными фото, ZIP и прежние генеративные промпты не переносятся.

**REJECTED как способ реализации:** дёрганая камера, замена настоящих этикеток сгенерированными, подмена упаковок похожими. Сам v2 пользователь просил доработать, а не явно отклонил целиком; поэтому он SUPERSEDED, а не REJECTED.

Тест встроенного генератора выполнен ранее, но безымянная тестовая канистра — **DRAFT как дизайн-материал**, не продукт ARAL. В этот пакет не включена. Восемь новых рекламных кадров v3 не созданы; промпты не считаются результатом генерации.

## 3. Общие решения сайта — уже есть в GitHub

Источник ниже — существующее [MASTER_TZ_ARAL_v1.0_FINAL_DRAFT.md](../../briefs/MASTER_TZ_ARAL_v1.0_FINAL_DRAFT.md), с явно помеченными утверждёнными разделами. Его название FINAL_DRAFT не превращает весь документ в утверждённый. Эти решения не присваиваются этому чату и повторно не выгружаются.

| Область | Что сохраняем / статус | Канонический раздел |
|---|---|---|
| Разделение по Kärcher | **APPROVED:** «Для бизнеса» / «Для автомобиля», крупные маршруты внутри единого бренда; перенос логики, не копирование дизайна Kärcher | §0.1, §2.3, §5 блок 2 |

| Каталог | **APPROVED по направлению:** светлая сетка 3–4 карточки, фильтры слева desktop, сортировка, минимум шума. Финальные категории и способ загрузки остаются открытыми | §7; [Decision Log](../../briefs/ARAL_DECISION_LOG_v1.0.md) |
| Product Detail / Compare | **APPROVED:** секции desktop, аккордеоны mobile, ключевые характеристики с раскрываемым полным блоком, до четырёх товаров в сравнении | §0.7, §3.3, §8 |
| Mega-menu | **APPROVED по UX:** полноширинная панель, hover/click, активный +/caret, раскрытие сверху вниз, ориентир 250–350 мс, смена содержимого без обязательного закрытия; mobile drawer/аккордеоны без hover-only | §6 |
| Цвет и типографика | **APPROVED направление:** ARAL blue, white, navy, light gray, небольшие жёлтые акценты; сильная крупная типографика, воздух, реальные фото | §3.1 |
| Дизайн-система | **DRAFT / утверждение полного набора не найдено:** страница Figma существует, но точные HEX, font family, размеры, токены и все компоненты этим аудитом не объявляются утверждёнными | Figma 0:1 |

| EON EV | **REJECTED:** полностью исключён как визуальный стиль | §3.1 |

Ранние `design/branches/set_1/` и `set_2/` содержат рабочие варианты. Их предложения о цене, наличии, скидках и 3–5 teaser-карточках **SUPERSEDED в этих частях**: позднее ТЗ фиксирует отсутствие цен/остатков/checkout и четыре teaser-карточки. Это отдельный блок сайта, не число упаковок в HERO. Исходные документы оставлены без правок.
